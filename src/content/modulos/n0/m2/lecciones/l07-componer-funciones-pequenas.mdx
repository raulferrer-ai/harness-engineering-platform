## Respuesta corta

Componer es conectar funciones donde **la salida de una es la entrada de otra**: `normalizar` arregla el nombre, `totalArticulo` calcula el total en euros, `eurosACents` lo lleva a céntimos enteros y `centsAEuros` devuelve el decimal limpio. Una función compuesta no debe tapar los errores de las que usa: si `eurosACents` lanza `TypeError`, el problema sale **con su clase original** y la prueba lo comprueba. El módulo se cierra ejecutando la suite completa: `node --test`.

## Conceptos

### Composición en una línea

```js
// descripcion-articulo.js — compone las funciones del módulo (lección l07)
import { totalArticulo } from "./articulo.js";
import { centsAEuros, eurosACents } from "./dinero.js";
import { normalizar } from "./normalizar.js";

export function descripcionArticulo(articulo) {
  const nombre = normalizar(articulo.nombre);
  const total = centsAEuros(eurosACents(totalArticulo(articulo)));
  return `${nombre} — ${articulo.cantidad} uds × ${articulo.precio} EUR = ${total} EUR`;
}
```

Léelo como una cadena de transformaciones: nombre normalizado → total en euros → céntimos enteros (con `Math.round` dentro) → decimal presentable. Cada eslabón es una función del módulo con su contrato ya probado por separado; la composición solo los ordena. Y `centsAEuros(eurosACents(total))` no es decoración: fija el total a dos decimales **absorbiendo el ruido decimal** de la l04 (el caso `0.1 × 3` lo verás en la salida).

### Los errores se propagan

`descripcionArticulo` no envuelve nada en `try/catch`. Si el artículo lleva `precio: NaN`, `totalArticulo` devuelve `NaN`, `eurosACents` lanza `TypeError` y ese `TypeError` sale por arriba **intacto**. La tercera prueba del fichero lo asegura: tapar un error ajeno (por ejemplo, devolver `undefined`) ocultaría el problema real en producción.

### La suite completa

Los cinco ficheros `.test.js` del módulo viven en `ejemplos/`. Sin listarlos, `node --test` descubre y ejecuta todos los de la carpeta:

```sh
node --test
```

## Ejercicio

Amplía el conjunto con una función nueva y su fichero de pruebas: `aplicarDescuento(articulo, porcentaje)`.

Contrato: el porcentaje es un número entre `0` y `100`; devuelve el total del artículo con el descuento aplicado, **redondeado a céntimos** como en `descripcionArticulo`.

Esto se cumple cuando:

- `aplicarDescuento(crearArticulo("café", 2.5, 3), 10)` devuelve `6.75`;
- un porcentaje fuera de `0–100` lanza `RangeError` y uno que no es número lanza `TypeError`;
- la función **reutiliza** `totalArticulo`, `eurosACents` y `centsAEuros` en vez de reimplementarlos;
- `node --test` sobre tu carpeta termina en verde con la suma de todas las pruebas.

Pista: el total con descuento es `total * (1 - porcentaje / 100)`; pásalo por la pareja céntimos para fijar decimales.

## Solución explicada

```js
// descuento.js — el ejercicio resuelto (lección l07)
import { totalArticulo } from "./articulo.js";
import { centsAEuros, eurosACents } from "./dinero.js";

export function aplicarDescuento(articulo, porcentaje) {
  if (typeof porcentaje !== "number" || Number.isNaN(porcentaje)) {
    throw new TypeError("aplicarDescuento espera un número");
  }
  if (porcentaje < 0 || porcentaje > 100) {
    throw new RangeError("aplicarDescuento espera un porcentaje entre 0 y 100");
  }
  const total = totalArticulo(articulo);
  return centsAEuros(eurosACents(total * (1 - porcentaje / 100)));
}
```

El esqueleto de contrato es el de siempre (tipo → rango → cálculo), y el cálculo es la composición: el total cruza por céntimos para que `2.5 × 3 × 0.9` termine en `6.75` exacto y no en `6.750000000000001`.

## Errores comunes

- **Reimplementar en vez de componer.** Si la composición vuelve a multiplicar y redondear a mano, copias bugs futuros de las funciones originales. Importa y ordena.
- **Envolver los errores ajenos en `try/catch` vacío.** Convierte un `TypeError` informativo en un `undefined` silencioso. Propaga, o reintenta solo si sabes por qué.
- **Olvidar el `./` en los imports.** `from "normalizar.js"` no resuelve: en módulos ES las rutas relativas llevan `./` (m1, l04).
- **Ejecutar `node --test` desde otra carpeta.** Descubre pruebas donde estás: si estás en la raíz del proyecto, no encontrará las del módulo.
- **Ajustar la prueba al código roto.** Si el verde solo vuelve al tocar la aserción, el bug estaba en el código y ahora está tapado.
